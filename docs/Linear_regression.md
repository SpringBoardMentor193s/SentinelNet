# 📘 Linear Regression Documentation
## Introduction

Linear Regression is a supervised machine learning algorithm used for predicting a continuous outcome (dependent variable) based on one or more input features (independent variables).It assumes a linear relationship between input variables and the output.

## Types of Linear Regression


### Simple Linear Regression ###
 – Uses one independent variable to predict the dependent variable.
Example: Predicting salary based on years of experience.

### Multiple Linear Regression ###   
– Uses two or more independent variables.
Example: Predicting house price based on area, number of rooms, and location.

## Mathematical Representation

y=β0​+β1​x1​+β2​x2​+...+βn​xn​+ϵ

## Steps in Building a Linear Regression Model

1.Collect data (dataset with input features and target variable).

2.Preprocess data (handle missing values, scaling, encoding).

3.Split data into training and testing sets.

4.Fit the model on training data.

5.Make predictions on test data.

6.Evaluate the model using metrics.

## Advantages

Easy to understand and implement.

Works well with linearly related data.

Computationally efficient.
