# Machine Learning

Algorithms that can learn without being explicitly programmed.

# Types of Machine Learning

## Supervised Machine Learning

Supervised Learning consists of labeled data that can be categorised. This discovers the relationship between input features and target outcome.

- Classification: Classification determines whether the new data belongs to a particular group or another.
- Regression: Regression is used in prediction of continuous outcome that falls within the range.

## Unsupervised Machine Learning

Unsupervised Learning learns the underlying patterns of the unlabeled data and is used to group or cluster similar items together.

## Reinforcement Learning

Reinforcement Learning utilizes the reward system to promote a desired behavior and a penalty otherwise.

## Semi-Supervised Learning

Semi Supervised Learning uses both labeled as well as unlabeled data. This approach makes use of the labeled data to generate new labeled data to train the final model.

# Supervised Machine Learning Models

## 1. Linear Regression

It is mainly used for regression problems, to predict a continuous output(like price, salary). It shows the relationship between independent variables and dependent variables.

## 2. Decision Trees

A Decision tree algorithm is tree like structure of decision rules that are applied to the input features to predtict the outcomes.

## 3. Random Forest

Random Forest builds upon the drawbacks of the overfitting problem seen in decision tree models. It constructs multiple decision trees on randomly selected samples from the data. The final outcome is derived from the majority voting of all the trees in the forest.

## 4. Support Vector Machines

SVM are generally used for classification problems. SVM finds the hyperplane, which segregates the two classes and maximizes the margin between them.

## 5. Gradient Boosting Regressor

It is an ensemble model that combines several weak lerners to make a robust predictive model. It is good ar handling non-linearities and multicollinearity.

# Unsupervised Machine Learning Models

## 6. K-means Clustering

It determines k-clusters based on the Euclidean distance. It is used in customer segmentation and recommendation systems.

## 7. Principle Component Analysis

Principal component analysis (PCA) is a statistical procedure that is used to summarize the information from a large data set by projecting it to a lower dimensional subspace. It is also called a dimensionality reduction technique that ensures retaining the essential parts of the data with higher information.

## 8. Hierarchical Clustering

It is a bottom-up approach where each data point is treated as its own cluster, and then the closest two clusters are merged together iteratively. Its biggest advantage over K-means clustering is that it does not require the user to specify the expected number of clusters at the onset. It finds application in document clustering based on similarity.

## 9. Apriori Algorithm

A rule-based approach that identifies the most frequent itemset in a given dataset where prior knowledge of frequent itemset properties is used. Market basket analysis employs this algorithm to help behemoths like Amazon and Netflix in translating the heaps of information about their users into simple rules of product recommendations.
