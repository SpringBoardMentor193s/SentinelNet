 # 📘 Simple Documentation for ML Models:
## 🔹 1. Linear Regression

Definition: A supervised ML algorithm used to predict a continuous value based on input features.

Use Cases: Predicting house prices, sales forecasting, salary prediction.

How it Works: Fits a straight line (y = mx + c) through the data that minimizes the error between predicted and actual values.

Pros: Simple, easy to understand, interpretable.

Cons: Assumes linear relationship, sensitive to outliers.

### Example: Predict house price from square footage.

## 🔹 2. Logistic Regression

Definition: A supervised ML algorithm used to predict a continuous value based on input features.

Use Cases: Predicting house prices, sales forecasting, salary prediction.

How it Works: Fits a straight line (y = mx + c) through the data that minimizes the error between predicted and actual values.

Pros: Simple, easy to understand, interpretable.

Cons: Assumes linear relationship, sensitive to outliers.

### Example: Predicting house price based on square footage.

## 🔹 3.Decision Tree

Definition: A model that splits data into branches based on feature conditions.

How it works: Creates a tree-like structure with nodes (questions) and leaves (predictions).

Use Cases: Loan approval, customer segmentation, medical diagnosis.

Advantages: Easy to visualize, handles categorical & numerical data.

Limitations: Can overfit easily, unstable with small changes in data.

### Example: Approving or rejecting a loan application based on income and credit score.

## 🔹4. Random Forest

Definition: An ensemble learning algorithm that combines multiple decision trees.

Use Cases: Stock market prediction, recommendation systems, credit risk modeling.

How it Works: Builds multiple decision trees on random subsets of data and averages their results for better accuracy.

Pros: Reduces overfitting, works well with large datasets, more accurate than a single tree.

Cons: Computationally expensive, less interpretable.

### Example: Predicting whether a transaction is fraudulent.

## 🔹5. Support Vector Machine (SVM)

Definition: A supervised ML algorithm mainly used for classification.

Use Cases: Image classification, text categorization, handwriting recognition.

How it Works: Finds the best boundary (hyperplane) that separates classes with maximum margin.

Pros: Effective in high-dimensional spaces, works well for small datasets.

Cons: Slow with large datasets, harder to interpret.

### Example: Classifying handwritten digits (0–9).

## 🔹6. Support Vector Machine (SVM)

Definition: A supervised ML algorithm mainly for classification, also used in regression.

Use Cases: Image classification, text categorization, handwriting recognition.

How it Works: Finds the best boundary (hyperplane) that separates classes with maximum margin.

Pros: Works well with high-dimensional data, effective with clear separation.

Cons: Slow on large datasets, harder to interpret, sensitive to parameters.

### Example: Classifying handwritten digits (0–9).
