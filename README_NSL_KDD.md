# **NSL-KDD Intrusion Detection System**

## **Overview**
This project focuses on building a **Network Intrusion Detection System (NIDS)** using the **NSL-KDD dataset**, a widely used benchmark for evaluating intrusion detection techniques. The system applies **machine learning models** to classify network traffic into **normal** or **attack categories**, helping to detect anomalies in network behavior.

---

## **Objectives**
- Preprocess and clean the NSL-KDD dataset  
- Extract relevant features for intrusion detection  
- Train and evaluate multiple ML models  
- Compare results using metrics like **Accuracy, Precision, Recall, F1-score**  
- Provide insights on effective models for real-world intrusion detection  

---

## **Features**
✔ Supports binary (Normal vs Attack) and multi-class classification  
✔ Data preprocessing & feature engineering pipeline  
✔ Benchmarking across multiple ML algorithms  
✔ Visualizations for dataset distribution & performance metrics  
✔ Extensible design for future datasets  

---

## **Tech Stack**
- **Language:** Python  
- **Libraries:** Pandas, NumPy, Scikit-learn, Matplotlib, Seaborn  
- **Tools:** Jupyter Notebook / Google Colab  
- **Dataset:** [NSL-KDD](https://www.kaggle.com/datasets/hassan06/nslkdd)  

---

## **Dataset Information**
- **NSL-KDD** is an improved version of the KDD Cup 1999 dataset.  
- It removes redundant records and balances class distribution, making it more suitable for ML-based intrusion detection research.  
- Attack categories include:  
  - **DoS (Denial of Service)**  
  - **Probe (Surveillance/Scanning)**  
  - **R2L (Remote to Local)**  
  - **U2R (User to Root)**  

---

## **Future Scope**
- Apply **deep learning (CNN, LSTM, GRU)** for sequential traffic analysis  
- Deploy a **real-time intrusion detection dashboard**  
- Explore **ensemble methods** for improved accuracy  
- Extend testing with **CICIDS 2017 dataset** for modern attack patterns
